# govt-proposal-skill

정부지원 사업계획서·연구개발계획서를 **이해·구조화·정렬** 순서로 쓰게 하는 Claude 스킬입니다.

AI에게 계획서를 바로 맡기면 양식 칸은 채워지지만 전략은 비어 있기 쉽습니다. 이 스킬은 빈칸을 채우기 전에 **제안 전략을 먼저 설계**하게 합니다. 핵심 키워드 3개를 정하고, 그 키워드가 배경·필요성·개발내용·사업화를 끝까지 관통하게 하며, 모든 주장에 입증 방안을 붙입니다.

## 무엇을 하나요

| 단계 | 하는 일 | 결과 파일 |
|---|---|---|
| 1. 입력 자료 | 공고문·작성양식·기업정보·심사표(지정공모면 RFP)를 읽고, 공고문 안의 심사표를 찾습니다 | `00_입력/` |
| 2. 작업 폴더 | 폴더를 만들고, 이미 있으면 진행 상태를 보고 이어 갑니다 | — |
| 3. 셀프 인터뷰 | 한 번에 한 문항씩 묻고 답을 받아 아이디어와 테마를 확정합니다. **대화는 이 단계에서만** 합니다 | `01_아이디어.md` |
| 4. 이해 | 목차마다 양식 지침(원문)·의도·입증 방안을 정리합니다 | `02_이해.md` |
| 5. 구조화 | 목차 × 키워드 매트릭스와 입증 전략을 만듭니다 | `03_구조화.md` |
| 6. 정렬 | 매트릭스를 가로(겹침·누락), 세로(논리 흐름)로 검토해 스스로 고칩니다 | `04_정렬.md` |
| 7. 본문 | 양식 대항목마다 블록 구조로 본문을 쓰고 점검합니다 | `05_본문/*.md` |
| 8. 병합 | 전략 검토 + 본문 + 준비할 입증 자료를 한 파일로 합칩니다 | `06_최종.md` |
| 9. 다듬기 | 교재에서 고친 파일을 다시 주면, 고친 항목만 문장 규칙에 맞춥니다 | `06_최종.md` |

3단계에서 확정한 뒤에는 묻지 않고 끝까지 진행합니다. 섹션만, 검토만, 과제명만 같은 부분 요청도 됩니다.

## 이렇게 씁니다

- **모든 섹션을 같은 블록 구조로**: 상위 메시지(3분할) + (말머리) 세부(2분할) + 입증 방안
- **설명하지 않고 입증합니다**: 사례·실적·특허로 답합니다
- **지어내지 않습니다**: 기업정보에 없는 실적·수치는 `[예시]`로 형식만 보이고 「준비할 입증 자료」에 올립니다. 간접비 요율·참여율 상한처럼 규정이 정하는 값은 `[기준]`을 붙여 원문 확인을 요구합니다
- **양식을 바꾸지 않습니다**: 목차 번호·항목명·분량·하위 문항은 양식 그대로 둡니다
- **한글에 옮기기 쉽게**: 본문에는 마크다운 표를 만들지 않습니다

## 설치

`govt-proposal/` 폴더 하나가 스킬입니다.

- **Claude 앱(claude.ai)**: `govt-proposal/` 폴더를 zip으로 묶어 설정의 스킬 메뉴에서 업로드합니다.
- **Claude Code**: `govt-proposal/` 폴더를 `~/.claude/skills/` 아래에 복사합니다.

설치한 뒤 "사업계획서", "공고문", "심사표", "TIPS", "예비창업패키지" 같은 말을 꺼내면 스킬이 불려 옵니다.

## 구성

```
govt-proposal/
├── SKILL.md                 스킬 본문(단계·판단 기준·금지사항)
├── references/              단계별로 읽는 자료
│   ├── 00_단계별_진행.md     4~9단계 상세, 부분 요청표
│   ├── 01_문장구조.md        블록 구조·3분할·2분할 규칙
│   ├── 02_입증전략.md
│   ├── 03_인터뷰_설계.md
│   ├── 04_구조화_유형별.md
│   └── 06_형식항목.md        사업비·일정·인력·컨소시엄·발표
├── assets/
│   └── 최종산출물_포맷.md     06_최종.md 형식과 섹션별 예시
└── scripts/                 Python이 있으면 씁니다(없어도 진행)
    ├── extract_doc.py       한글(hwpx·hwp)·워드·PDF 텍스트 추출
    ├── init_workspace.py    작업 폴더 생성·진행 상태
    ├── find_rubric.py       공고문 안의 심사표 찾기
    ├── lint_text.py         분량·완결형·2분할·금지어 점검
    └── audit_keywords.py    섹션별 키워드 반복 검증
사업계획서실무교재.html        결과물(06_최종.md)을 넣어 보고 고치는 교재
```

`extract_doc.py`는 `.hwp`에 `olefile`, PDF에 `pypdf`가 필요합니다. 표 구조가 중요한 양식은 HWPX로 저장해 쓰는 편이 낫습니다.

## 사업계획서 실무 교재

`사업계획서실무교재.html`을 브라우저로 열고 `06_최종.md`를 넣으면 세 부분으로 나눠 보여 줍니다. 교재에서 고친 뒤 **전체 MD 복사**로 가져와 다시 주면 9단계(다듬기)가 이어집니다.
