# 정부지원 사업계획서 작성

계획서를 채우는 게 아니라 **제안 전략을 설계**한다. **키워드 3개**가 배경→필요성→개발내용→사업화를 세로로 관통하고(병렬 반복), 모든 주장에 **입증 방안**이 붙는다.

## Instructions

**대화는 3단계 한 곳에서만 한다.** 대신 **거기서는 반드시 대화한다** — 한 번에 한 문항씩 묻고 답을 기다린다. 확정 후에는 묻지 않고 끝까지 자동으로 진행한다. 수정은 교재에서 사용자가 고친 뒤 9단계로 돌아온다.

1. **입력 자료** — 공고문·작성양식·기업정보·심사표. 지정공모면 RFP. 없는 자료는 무엇을 못 하는지 한 줄로 알리고 진행. 한글은 **전부 `extract_doc.py --tables`** 로 추출한다 — 양식도 공고문도 표가 본문이다. **심사표는 별도 파일이 없어도 공고문 안에 있는 경우가 많다 — `find_rubric.py`로 먼저 찾는다.**
2. **작업 폴더** — `init_workspace.py`. 기존 폴더면 상태를 보고 이어간다.
3. **셀프 인터뷰** → `01_아이디어.md` — `03_인터뷰_설계.md`. **① 아이디어 여부 → ② 인터뷰 → ③ 테마 확정 → ④ 세부** 순서다. **첫 질문은 언제나 "구상하신 아이디어가 있으신가요?"** — 자료가 충실해도 건너뛰지 않는다. **테마는 인터뷰의 결과이지 전제가 아니다** — ①②를 건너뛰고 ③부터 시작하지 않는다. 마지막에 확정 요약으로 **한 번만 승인**받는다.
4. **#이해** → `02_이해.md` — 모든 목차의 양식 지침(원문)·의도·입증 방안. `00_단계별_진행.md` 4절
5. **#구조화** → `03_구조화.md` — 목차×키워드 매트릭스 + 입증전략 행. `04_구조화_유형별.md`
6. **#정렬** → `04_정렬.md` — `04_구조화_유형별.md` 검토 축 표. 매트릭스를 두 방향으로 읽는다. **가로 = MECE**(겹침·누락), **세로 = 논리 흐름**(관통 논리 한 줄. 목차 나열 금지, 끊긴 곳만 번호로). `가로 검토` 열·`세로 검토` 행을 채우고 수정할 점을 **스스로 반영**해 매트릭스를 고친다. `audit_keywords.py`
7. **본문** → `05_본문/*.md` — `01_문장구조.md`를 읽고 시작. 양식 대항목마다 한 파일. `lint_text.py`로 점검 후 지적 사항을 스스로 고친다.
8. **병합** → `06_최종.md` — 아래 Output Format의 고정 구조. 이 파일은 교재가 읽어 화면을 만든다(`assets/최종산출물_포맷.md` 3.11 계약). 전달하며 **준비할 입증 자료 목록**과 교재 안내를 함께 준다.
9. **다듬기** — 사용자가 교재에서 고쳐 저장한 `06_최종.md`를 다시 주면: `<!-- 수정됨 -->` 표시된 항목만, 사용자가 바꾼 내용은 **그대로 유지**하고 문장 규칙(3분할·2분할·말머리·금지어)만 맞춘다. 표시를 지우고 바꾼 줄 목록을 보고한다. 이 루프를 반복한다.

부분 요청(섹션만·검토만·과제명만)은 `00_단계별_진행.md` 부분 요청표.

## 판단 기준

- **모든 섹션을 같은 블록 구조로.** 상위 메시지 3분할 + (말머리) 2분할 세부 + 입증 방안. 정의된 5개 섹션은 `01_문장구조.md` 3장, 그 밖은 3.6절 일반형. **본문은 무조건 블록 구조다.** 양식이 "서술형"을 요구해도 묻지 않고 유지하며, 한 줄로 알리기만 한다(스킬 정책).
- **항목마다 수준이 다르다.** 1수준(배경·개발내용 등)은 전략대로 문장을, 2수준(요약·정량 목표)은 `` `[예시]` `` 로 형식을, **3수준(사업비·일정·인력·컨소시엄·발표)은 규정이 형식을 정하므로 `` `[기준]` `` 을 붙이고 원문 확인을 요구한다.** `06_형식항목.md`.
- **첨부 항목에는 본문을 쓰지 않는다.** 동의서·서약서·증명서·신고필증은 `※` 한 줄로 준비할 것만 적고 `# 준비할 입증 자료`에 올린다.
- **양식이 정하는 것**: 목차 번호·항목명·분량·하위 문항·표 칸. 하위 문항은 소제목으로.
- **양식의 표는 대부분 표가 아니다.** 한글 양식은 글 쓰는 자리도 표로 만든다. `extract_doc.py --tables`가 붙이는 이름표(`표:본문칸` 등 6종)를 보고 판단한다. `01_문장구조.md` 0장.
- **본문에는 마크다운 표를 만들지 않는다.** 양식의 표는 "이런 항목을 쓰라"는 **작성 요령**이다. 요구 항목을 텍스트로 쓴다 — 한글에 옮길 때 마크다운 표는 깨진다. `01_문장구조.md` 6장.
- **작성 요령이 있으면 그것부터 따른다.** `※` 문구, `* 최대 N페이지`, 표의 열 제목이 전부 요령이다.
- **헤딩은 양식 항목까지만.** `#` 대항목, `##` 소항목. 세부 개발 항목은 헤딩이 아니라 블록 안 번호줄. 양식 번호와 겹치면 ①②③.
- **설명하지 말고 입증한다.** 기술로 답하면 논쟁, 사례·실적·특허로 답해야 신뢰.
- **정량 목표**는 `지표 / 단위 / 현재 / 국내외 최고 / 목표 / 측정 방법`. 양식에 성능지표 표가 있으면 그 칸에, 없으면 블록 안 `① 지표: 현재 → 목표 (측정 방법)` 줄로. 모르면 `` `[예시]` `` 로 형식을 보이고 준비할 입증 자료 1순위에 "현재 수준 측정"을 올린다.

## Output Format

```
<작업폴더>/
├── 00_입력/  01_아이디어.md  02_이해.md  03_구조화.md  04_정렬.md
├── 05_본문/   양식 대항목마다 한 파일 (1_기술개발목표.md …)
└── 06_최종.md  ← 전달물. 아래 고정 구조
```

`06_최종.md`는 양식과 무관하게 **앞부분이 고정**이다. 교재가 이 구조를 읽어 화면을 만든다.

```markdown
# 전략 검토
## 핵심 키워드
(개조식) 키워드 3개를 각각 한 블록 — 상위 메시지 + (정책 근거) (기업 역량) (계획서 역할). 본문과 같은 문장 규칙
## 전략 매트릭스
(04_정렬.md의 표 그대로) | 목차 | #키워드1 | #키워드2 | #키워드3 | 가로 검토 |  + 입증전략 행 + 세로 검토 행
## 유지할 점 / 수정할 점
# 1. (양식 대항목)
## 1-1. (양식 소항목)
1. (#키워드) 상위 메시지 — 3분할, 명사 위주, 완결형
  - (말머리) 단위 1 ─연결어미─ 단위 2     ← 2분할: 조각 나열 금지, 명사형 종결, 30자 안팎
  (입증 방안: 필요 자료)
# 준비할 입증 자료
(우선순위 목록)
```

`+`, `─연결어미─`, `{ }`는 표기용이다. 출력에 쓰지 않는다.

## 금지사항

- **규정이 정하는 값을 추측하지 않는다.** 간접비 요율·대응자금 비율·참여율 상한·개발기간 상한 등은 `` `[기준]` `` 을 붙이고 `# 확인할 규정` 에 올린다. 지어내면 반려 사유다.
- 기업정보 밖의 실적·수치·거래처·특허를 **사실인 척 쓰지 않는다.** 대신 `` `[예시]` `` 표시를 붙여 형식을 보여주고, 같은 항목을 `# 준비할 입증 자료`에 올린다. 빈칸으로 두면 무엇을 넣어야 할지 알 수 없다. **표시 없는 수치가 사고다.**
- 추상 형용사로만 채운 문장(극대화·효율화·고도화된), 상투어(사료된다·대두되고 있다). 숫자로 대체.
- 양식의 목차·항목명·분량을 바꾸지 않는다.
- **인터뷰를 건너뛰지 않는다.** 자료에서 아이디어·키워드를 혼자 정해 요약부터 내놓는 것은 인터뷰가 아니다. 자료는 보기를 만드는 재료이고, 고르는 것은 사람이다.
- **테마가 확정되기 전에 세부를 묻거나 본문을 쓰지 않는다.** 주제가 바뀌면 목표·입증·파트너가 전부 바뀐다.
- 3단계 확정 전에 본문을 쓰지 않고, 확정 후에는 되묻지 않는다.
- 다듬기 때 사용자가 고친 내용을 되돌리지 않는다.

## Scripts

Python이 있으면 쓴다. 없으면 같은 판단을 직접 한다 — 글자수·섹션별 키워드 반복·세부 줄의 연결어미와 말머리.

```
scripts/extract_doc.py <파일> [--tables] -o <out.md>   한글·워드·PDF 추출
scripts/init_workspace.py <폴더>                       폴더 생성·진행 상태
scripts/lint_text.py <md|폴더> [--limit N]             분량·완결형·2분할·금지어
scripts/audit_keywords.py <md|폴더> --keywords A,B,C   키워드 반복 검증 (병합본은 `--h1`)
scripts/find_rubric.py <공고문.md> [--all]             공고문 안의 심사표 찾기
```
