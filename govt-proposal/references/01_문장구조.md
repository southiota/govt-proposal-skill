# 문장 구조

## 0. 양식의 표 — 대부분 표가 아니다

한글 양식은 **글 쓰는 자리도 표로 만든다.** 실제 양식(대구경북청 연구개발계획서)의 표 46개 중 34개가 채우는 표가 아니었다.

가장 흔한 실수는 **본문칸을 표로 착각해 마크다운 표를 만드는 것**이다. 양식이 표를 그려 놨다고 표로 답하면 안 된다. 1칸짜리 표는 그냥 원고지다.

`extract_doc.py --tables`가 표마다 이름표를 붙인다. 그것만 보고 판단한다.

| 이름표 | 무엇을 하나 |
|---|---|
| `표:제목띠` | 양식 항목 제목. `#` 헤딩으로 옮기고 내용은 이어지는 본문칸에 |
| `표:본문칸` | **글 쓰는 자리.** 블록을 쓴다. 마크다운 표를 만들지 않는다 |
| `표:지침칸` | 작성 지침(`※`). 여기 쓰지 않는다. `02_이해.md`에 옮기고 본문에 반영 |
| `표:머리글칸` | 이미 적힌 문구. 그대로 둔다 |
| `표:라벨값표` | 왼쪽 라벨은 두고 오른쪽 칸만 채운다 |
| `표:데이터표(N열)` | 요구 항목이 정해진 자리. **표로 그리지 말고** 열 제목을 말머리로 삼아 텍스트로 (6장) |

실제로 이렇게 나온다.

```
<!-- 표:제목띠 -->        ← 헤딩으로:  # 1. 기술개발 목표
| 1. 기술개발 목표 | |

<!-- 표:본문칸 -->        ← 여기에 블록을 쓴다
| |

<!-- 표:지침칸 -->        ← 쓰는 곳이 아니다. 지침이다
| ※ R&D 결과의 검증 방법과 계획은 반드시 포함 |
```

### 본문칸 — 블록을 쓴다

표가 아니므로 1~3장 규칙을 그대로 쓴다.

```
1. (#키워드) 상위 메시지 — 3분할, 명사 위주, 완결형
  - (말머리) 단위 1 ─연결어미─ 단위 2
  (입증 방안: 필요 자료)
```

### 데이터표·라벨값표 — 항목을 텍스트로 쓴다

**본문에 마크다운 표를 만들지 않는다.** 양식의 표는 "이런 항목들을 이렇게 쓰라"는 **작성 요령**이지
표를 그려 달라는 뜻이 아니다. 수강생이 한글 양식에 옮길 때 마크다운 표는 깨지고 칸마다 다시 나눠야 한다.

쓰는 법은 6장. 열 제목을 말머리로 바꿔 블록으로 쓴다.

### 라벨값표 — 과제 개요가 여기다

`과제명 / 개발 목표 / 개발 방법 / 연구팀 구성 / 기대효과` 5행이 오른쪽 빈칸을 기다린다.
양식 첫 항목이고 심사자가 가장 먼저 본다. **1페이지 제한이 있어도 여기에 힘을 쓴다.**
왼쪽 라벨을 말머리로 삼아 텍스트로 쓴다 — 6장.

모든 섹션을 같은 블록으로 쓴다. 양식이 정하는 것은 목차명·분량·하위 문항·표 칸뿐이다.

| | 구조 | 형태 |
|---|---|---|
| 상위 메시지 | **3분할** {A}+{B}+{C} | 명사 위주, 완결형 — 한 줄로 블록 전체를 파악 |
| 세부 내용 | **(말머리) + 2분할** — 두 단위를 조사·연결어미로 이은 **한 문장** | 30자 안팎, 명사형 종결 |
| 입증 방안 | 블록 끝 한 줄 | 필요 자료의 유형 |

`{ }` `+`는 경계 표기. 출력에 쓰지 않는다.

## 1. 2분할 — 조각을 나열하지 않는다

```
⭕ (현 상황 한계) 기존 고정형 자동화의 경직성으로 인한 돌발 변수 대응력 부재
❌ (현황) 범용 알고리즘 초고속 회전 대응 · 토크 리플로 응답성 저하   ← 조각 나열
❌ (현황) 비정형 환경 대응이 어렵다                                ← 1분할·서술형
```

| 관계 | 연결 | 예 |
|---|---|---|
| 인과 | ~로 인한 / ~에 따른 | 경직성**으로 인한** 대응력 부재 |
| 목적 | ~를 위한 | 대형 금형 제작**을 위한** 복합소재 개발 |
| 수단 | ~기반 / ~가능한 / ~활용 | 인지·판단이 **가능한** 피지컬 AI **기반** 최적화 구현 |
| 병렬 | 및 / ~과 | 경쟁 심화 **및** 인력 부족 가속화 |
| 전환 | ~에서 ~로 | 시계열 분석**에서** 유연 분석**으로** 확장 |

종결은 명사형 — 급증·부재·확산·실현·필수·한계·보유·적용·확장·활용·개발·구현·가속화. `~다`로 끝나면 서술형이다.
`·`는 열거(초·중학교)에만 쓴다. 공백 있는 ` · `로 절을 붙이지 않는다.

## 2. 과제명 — 3단

```
{대상/분야} {기술/방법} {결과물/목표}
```
| 유형 | 예 |
|---|---|
| 기술 선도형 | {자율주행 돌발상황} {0.1초 이내 대응} {초저지연 에지 컴퓨팅 기술 개발} |
| 문제 해결형 | {산화 공정 OES LSTM 알고리즘으로} {웨이퍼 불량률} {30% 저감} |
| 서비스 체감형 | {전시 만족도} {40% 향상을 위한} {행동 분석 기반 콘텐츠 리워드 플랫폼} |

결과물과 수치가 보여야 한다. "~개발"로 끝나면 3단째가 비어 있는 것이다.

## 3. 섹션별 구성단위·말머리

각 섹션: 3분할 구성단위 → 대체 패턴 → 말머리 세트 → 설득 포인트 → 예 1블록. 세트에 없는 역할의 줄이 필요하면 다른 섹션의 말머리를 빌린다.

### 3.1 연구배경 — 정부는 무슨 말을 하는가

정부가 지금 중요하게 보는 과제에 개발 기술이 어떻게 연결되는지. 정부 키워드는 '혹하는 것'이 아니라 '방향을 같이하는 것'.

3분할 `{내/외부 환경} {현 상황} {나아갈 방향}`
대체 `{정책·시장·기술 변화}+{현장 문제}+{필요 이유}` / `{수요 확대}+{기존 한계}+{개발 필요성}` / `{시장·정책 요구}+{기술 부족}+{당위성}`
말머리 `(내/외부 환경) (현 상황 한계) (기술 개발)` · 설득 리포트·통계·기사
```
1. (#피지컬AI) 지능형 제조 전환 가속화 대응 피지컬 AI 기반 자율 공정 최적화 기술 필요
  - (내/외부 환경) 글로벌 제조 패권 경쟁 심화 및 산업계 노동 인력 부족 가속화
  - (현 상황 한계) 기존 고정형 자동화의 경직성으로 인한 돌발 변수 대응력 부재
  - (기술 개발) 실시간 인지·판단이 가능한 피지컬 AI 기반 자율 공정 최적화 구현
  (입증 방안: 제조 AI 로드맵 문구, 설비 MTBF 통계, 인력 수급 대책 지표)
```

### 3.2 목적·필요성 — 정부의 언어로

정부의 언어는 심사자가 빠르고 동일하게 읽는다.

3분할 `{해결할 문제} {개발 방향·방법} {가치·성과}`
대체 `{현장 문제}+{기존 한계}+{필요 이유}` / `{비효율·리스크}+{구조적 원인}+{개선 효과}` / `{요구 수준}+{미충족}+{개발 목표}`
말머리 `(해결할 문제) (개발 방향) (가치·성과)` · 설득 정부 정책·법·제도
```
1. (#물류자동화) 비정형 인식 한계 극복을 위한 VLM 제로샷 기반 물류 자동화 실현
  - (해결할 문제) 신규 품목마다 발생하는 방대한 데이터 라벨링과 재학습 비용의 한계
  - (개발 방향) 다품종 물류 환경에 즉각 대응 가능한 인간 수준의 시각 추론 지능 필수
  - (가치·성과) 데이터 구축 리소스 80% 절감 및 중단 없는 신규 품목 즉시 투입 실현
  (입증 방안: 정부 8대 핵심기술 문구, 라벨링 공수 실측 데이터)
```

### 3.3 연구개발내용 — 설명하지 말고 입증하자

방법 설명에 빠지면 기술 논쟁이 된다. 힘은 가능성 입증에. 설득 포인트(책임자·역량)를 상위 메시지 아래 `※`로.

3분할 `{무엇을 개발} {개발 방법} {성능·효과}`
대체 `{핵심 문제}+{접근}+{개발 내용}` / `{개발 대상}+{기술·방법론}+{기능·효과}` / `{개발 항목}+{구현 방식}+{성과}`
말머리 `(개발 대상) (적용 방법) (성능·효과)` · 설득 책임자 경력, 기관 역량, 개념도·프로세스도
```
1. (#초고속구동) 초고속 회전 영역 연산 부하 문제 해소를 위한 SiC 고주파 스위칭 기반 30,000rpm 안정 구동 실현
  ※ 세부 책임자: 00수석연구원, SiC 전용 설계 경험 (특허 0000)
  ① SiC 기반 고효율 인버터 하드웨어 구축
    - (개발 대상) 고주파 대역 손실 저감을 위한 SiC MOSFET 기반 인버터 하드웨어 설계
    - (적용 방법) 저인덕턴스 버스바 및 게이트 드라이버 최적화를 통한 EMI/EMC 노이즈 저감
  (입증 방안: 기존 연구 성과, 적용 이론·방법론을 도표·수식으로 가시화)
```
'배경-목적'과 정렬이 어려우면 개발 내용을 기준으로 앞을 재설계하는 편이 낫다.

### 3.4 선행연구 — 가능한 칸을 모두 채우자

전략은 레고다. 딱 맞는 조각이 아니라 어울리는 조각을 조립한다.

3분할 `{보유 기술} {활용 방법} {효과}`
대체 `{기존 수준}+{성과와 한계}+{활용}` / `{선행기술}+{부족한 점}+{차별성}` / `{성과}+{현장 한계}+{개선점}`
말머리 `(기존 기술) (활용 방법) (한계 및 보완) (활용 방향)` · 설득 특허·논문·과제·납품
```
1. (#공정이상감지) 복합변수 기반 감지 기술 보유를 통한 AI 에이전트 적용 실시간 안전 관리 기반 마련
  ※ 납품 00건, LSTM 감지 시스템 특허(등록 000)
  - (기존 기술) 센서 데이터 기반 공정 이상감지 및 설비 상태 모니터링 기술 보유
  - (활용 방법) 현장 데이터를 실시간 수집·분석하는 방식의 AI 에이전트 기술 적용
  - (한계 및 보완) 단순 시계열 분석(LSTM)에서 다변수 고려 유연 분석 에이전트로 확장
  - (활용 방향) 현장 대응성 강화를 통한 실시간 안전·공정 관리 체계 구축에 활용
  (입증 방안: 등록특허 번호·청구항, 납품 증빙, 논문)
```

### 3.5 사업화 — 논리보다 입증

기업 생존력을 확인하는 자리. 막연한 추정 대신 확보된 수요.

3분할 `{고객·시장} {진입·접근} {규모·확산력}`
대체 `{제공 가치}+{사업화 모델}+{성과 계획}` / `{누구에게}+{무엇을 어떻게}+{확산}` / `{시장}+{제품 형태}+{진입·성장 전략}`
말머리 `(타겟 시장) (유통 채널) (사업 목표)` · 설득 MOU·발주서·구매의향서·수익 내역
```
1. (#인접시장확장) 산업용 로봇 기업의 기존 수요 기반 인접 시장 수평 확장을 통한 단기 거래처 대비 50% 매출 확보
  - (타겟 시장) 산업용·서비스용 로봇을 개발·제조하는 기존 납품 인접 업종 기업
  - (유통 채널) 기존 고객사 및 네트워크 중심의 신규 영업 비용 없는 제안·공급
  - (사업 목표) 단기 기존 거래처 대비 50% 및 중장기 국내 점유율 10% 확보
  ※ 20XX년 납품 00건, 수요처 00곳, 수익 00억
  (입증 방안: 구매의향서, MOU, 거래 내역)
```
목표매출: 개발완료 후 5개년 + 산출근거. `0,000천 원`처럼 딱 떨어지는 수치 지양.

### 3.6 그 밖의 섹션 — 일반형

같은 블록 구조. 구성단위·말머리는 그 섹션이 심사자에게 답할 질문에서 뽑는다.

| 섹션 | 3분할 | 말머리 | 설득 |
|---|---|---|---|
| 추진 체계 | {누가} {무엇을 맡아} {어떻게 협업} | (담당 기관) (역할) (협업 방식) | 협약서, 참여 인력 경력 |
| 연차별 일정 | {단계} {기간·산출물} {다음 연결} | (설계) (개발) (실증) 또는 (1차년) (2차년) | 마일스톤 |
| 사업비 | {항목} {비중} {집중 이유} | 양식 비목 (인건비) (연구장비) … | 산출 근거 |
| 기대효과 | {효과 종류} {규모·수치} {근거} | (기술적) (경제적) (사회적) | 추정 근거, 유사 사례 |
| 해외진출 | {대상 시장} {진입 경로} {근거} | (목표 시장) (진입 방법) (보유 자산) | 해외 특허, 파트너 |
| 핵심 키워드 | {무엇을 축으로} {정책 근거} {기업 역량} | (정책 근거) (기업 역량) (계획서 역할) | 공고문 문구 직접 인용, 기업정보 |

```
1. (#교육격차해소) 지도 인력 없는 방과후 교실의 실습 완주율 30% 향상을 통한 지역 간 교육 격차 완화
  - (기술적) 온디바이스 추론 엔진 확보로 클라우드 없는 교육 AI 상용화 선례
  - (경제적) 기존 고객 30개 기관 업그레이드 및 신규 50개 도입으로 3년 매출 00억
  - (사회적) 비수도권 방과후 실습 참여율 격차 00%p 축소
  (입증 방안: 늘봄학교 정책 통계, 자사 납품 이력 기반 추정)
```

양식이 표 칸을 주면(성능지표·연구원 현황·연차별 사업비) 그 항목들을 **텍스트로** 쓴다. 6장.

## 4. 금지

- 추상 형용사로만 채운 문장 — 극대화·효율화·고도화된·혁신적인. 숫자로. ("위상 최적화" 같은 기술 용어는 괜찮다)
- 상투어 — 사료된다·판단된다·대두되고 있다·각광
- 접속사로 시작 — 따라서·그러므로·이를 통해
- 상위 메시지가 명사 하나로 끝남 — "지능화 결여" ❌ → "지능화 결여로 수동 모니터링 의존, 비용 및 리스크 가중" ⭕

## 5. 가독성 기호

`→` 전후 비교 · `>>` 우위 · `↑↓` 증감 · `#` 반복 키워드 · `^(…)` 상첨자 부연 (한글에서 위 첨자로)

## 6. 양식의 표를 텍스트로 쓰기

양식이 표로 항목을 지시했다면 **그 항목 이름이 곧 말머리**다. 표를 그리지 말고 블록으로 쓴다.

### 열이 항목인 표 (성과지표·연차별 사업비)

```
| 지표 | 단위 | 현재 수준 | 국내외 최고 | 개발 목표 | 측정 방법 |   ← 양식이 준 열
```

행마다 한 블록. 열 제목을 말머리로.

**형식은 `(말머리) 값 — 근거`.** 값을 앞에, 근거를 ` — ` 뒤에 둔다.

```
1. (#키워드) 오프라인 실습 완주율 개선을 통한 무선망 취약 교실 실습 연속성 확보
  - (현재 수준) `[예시]` 62% — 실증 3개 교실 차시 단위 측정
  - (개발 목표) `[예시]` 85% — 차시 단위 완주율
  - (국내외 최고) `[예시]` 90% — 유사 제품 사양서 기준
  - (측정 방법) 완료 학생 수 ÷ 참여 학생 수 — 차시별 집계
  (입증 방안: 실증 교실 사전 측정 — 준비 필요)
```

지표가 셋이면 블록 셋. 한 블록에 몰아넣지 않는다.
` — ` 가 있는 줄은 값 나열로 보아 **2분할·길이 규칙에서 빠진다**(`lint_text.py`). 값과 근거만 다 있으면 된다.

### 행이 항목인 표 (과제 개요·참여인력)

왼쪽 라벨이 말머리다.

```
1. (#키워드) 무선망 단절 교실의 실습 연속성 확보를 위한 온디바이스 AI 교육 로봇 개발
  - (개발 목표) 서버 접속 없는 단말 내 추론 전환 및 완주율 `[예시]` 62%에서 85%로 향상
  - (개발 방법) 콘텐츠 모델 경량화 후 로봇 탑재 및 오프라인 시나리오 엔진 결합
  - (연구팀 구성) 로봇·AI 인력 15명 중 항목별 배치 및 경량화 검증 외부 위탁
  - (기대효과) 클라우드 없는 교육 AI 상용화 선례 및 취약 교실 격차 완화
```

### 사람이 여럿인 표 (연구원 현황)

한 사람이 한 줄. `이름 / 소속·직위 / 학력·전공 / 역할` 을 이어 쓴다.

```
1. (#키워드) 단독 수행 가능한 인력 구성을 통한 개발 항목별 책임 배치
  - (총괄) `[예시]` 김OO, 대표이사, 공학석사·전자공학 — 과제 총괄 및 실증 기관 협의
  - (설계) `[예시]` 이OO, 연구소장, 공학박사·로봇공학 — 단말 추론 구조 설계 총괄
  (입증 방안: 참여 연구원 경력기술서 — 준비 필요)
```

### 공통 규칙

- **모르는 칸은 비우지 않는다.** `[예시]` 표시를 붙여 형식을 보이고 `# 준비할 입증 자료`에 올린다
- 양식이 요구한 **항목을 하나도 빠뜨리지 않는다.** 열 제목·행 라벨을 그대로 대조한다
- 한글에 옮길 때는 이 줄들을 표 칸에 하나씩 넣으면 된다. 그래서 표로 그리지 않는 편이 빠르다
